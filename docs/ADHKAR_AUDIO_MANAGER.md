# Adhkar Audio Manager

وحدة مستقلة لإدارة أصوات الأذكار في تطبيق نور الإسلام.

## القواعد

- كتالوج الصوتيات موجود في `public/data/adhkar-audio-catalog.json` ويُجلب وقت التشغيل.
- كل تسجيل مرتبط بمفتاح القسم والقارئ ونوع التسجيل (`category` أو `item`).
- لا يوجد fallback بين الأقسام، ولا يُستخدم تسجيل قسم الصباح لقسم آخر.
- التسجيلات غير الموجودة تظهر للمستخدم كغير متوفرة بدل تشغيل ملف غير مطابق.
- لا يُضاف تسجيل إلى الكتالوج على أنه `verified` إلا بعد التحقق من الملف ومطابقة محتواه للنص وبقاء حقوق استخدامه واضحة.

## الواجهة البرمجية

`src/utils/adhkarAudioManager.ts` يوفر:

- تحميل الكتالوج والتحقق من بنيته.
- حل رابط تسجيل قسم أو ذكر محدد.
- فحص مصدر الصوت قبل التشغيل.
- تخزين التسجيلات في Cache API للاستخدام دون اتصال عند دعم المنصة.
- تشغيل تسجيل واحد وإيقافه ومنع تداخل مشغلين.

## الحالة الحالية

التسجيلات المحلية المطابقة المتوفرة حاليًا هي: أذكار الصباح، أذكار المساء، أذكار النوم، والوتر، بصوت العفاسي الموجود في حزمة التطبيق. بقية الأقسام لا تُربط بتسجيل بديل غير موثق؛ ستعرض رسالة عدم توفر الصوت إلى حين إضافة تسجيل مستقل موثق لها.

لا يمكن إثبات تطابق تسجيل صوتي مع نص ذكر آليًا من امتداده أو من استجابة HTTP؛ يلزم مراجعة بشرية للتسجيل نفسه قبل وضع `verified: true`.
