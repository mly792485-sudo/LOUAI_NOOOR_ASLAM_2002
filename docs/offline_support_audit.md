# تدقيق دعم العمل دون إنترنت

## ما هو محلي داخل حزمة التطبيق

الواجهة، بيانات الأذكار، قصص الأنبياء، السيرة، الصحابة والتابعين، الفقه، أسماء الله الحسنى، الأحاديث المحلية، بيانات المدن، نص القرآن الكامل، الحفظ والمفضلة والتقدم، وملفات الأذان وبعض الأذكار والرقية موجودة داخل المشروع أو في التخزين المحلي. هذه الأجزاء لا تحتاج اتصالًا بعد تثبيت التطبيق.

تم تحديث Service Worker ليحفظ حزمة JavaScript وCSS والصور والملفات الصوتية المحلية، ويعمل بمسار نسبي مناسب لـ GitHub Pages، مع صفحة بديلة عند فتح التطبيق دون اتصال. أضيف أيضًا manifest محلي للتثبيت كـ PWA.

## ما يعمل دون اتصال بعد التخزين أو التنزيل الأول

تفسير السعدي وابن كثير، صفحات صور المصحف، وبيانات بعض الخدمات التي سبق فتحها يمكن أن تعمل من IndexedDB أو Cache Storage بعد اكتمال التنزيل الأول. تنزيل التفسير الكامل من الشبكة غير مضمن تلقائيًا في الحزمة الحالية بسبب حجمه وحقوق إعادة التوزيع؛ يجب أن ينفذ المستخدم عملية التنزيل من داخل التطبيق حين تتوفر الشبكة.

## ما لا يمكن أن يكون حيًا دون اتصال

المستشار الذكي، تسجيل الدخول Firebase، مواقيت الصلاة التلقائية المعتمدة على API أو تحديد المدينة عبر reverse geocoding، الإذاعات المباشرة، روابط إحسان وواتساب والمشاركة الخارجية، وتلاوات القرآن البعيدة تحتاج إنترنت أو إعدادات نظام/خدمة خارجية. التطبيق يجب أن يبقى قابلًا للاستخدام كزائر مع المحتوى المحلي عند انقطاع الشبكة، ولا يصح الادعاء بأن هذه الخدمات الحية تعمل بلا اتصال.

## الاختبارات

بعد التعديل يجب تشغيل `npm run lint` و`npm run build` و`git diff --check` ثم `npx cap sync`. يلزم اختبار فعلي بتفعيل وضع الطيران على iPhone وAndroid؛ نجاح البناء وحده لا يثبت عمل الصوت في الخلفية أو الإشعارات عند قفل الشاشة.
